# yimwu-skills

AI Agent 技能集合，用于软件工程任务。

[English Version](README.md)

## 安装

```bash
pip install git+https://github.com/yimwu/yimwu-skills.git
```

安装所有技能到当前项目（默认）：

```bash
yimwu-skills
```

安装指定技能：

```bash
yimwu-skills vibe-project-standard
```

技能文件会复制到当前项目目录的 `.claude/skills/` 中。

## 技能列表

| 技能 | 描述 |
|------|------|
| [vibe-project-standard](skills/vibe-project-standard/) | Vibe Coding 项目规范化技能。指导从零构建生产级项目，包含 SDD/TDD 开发流程、CI/CD 配置、质量保证和发布流程。 |
