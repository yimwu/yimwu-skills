# yimwu-skills

A collection of AI agent skills for software engineering tasks.

[中文版](README-zh-CN.md)

## Installation

```bash
pip install git+https://github.com/yimwu/yimwu-skills.git
```

Install all skills into the current project (default):

```bash
yimwu-skills
```

Install specific skills:

```bash
yimwu-skills vibe-project-standard
```

Skills are copied into `.claude/skills/` in your current project directory.

## Skills

| Skill | Description |
|-------|-------------|
| [vibe-project-standard](skills/vibe-project-standard/) | Project standardization skill for vibe coding. Guide from zero to production-ready projects with SDD/TDD workflow, CI/CD configuration, quality assurance, and release process. |
